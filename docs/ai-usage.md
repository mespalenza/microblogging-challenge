# Uso de inteligencia artificial

Utilicé IA como apoyo durante el desarrollo para analizar la consigna, revisar
la implementación, detectar casos de prueba y discutir el diseño de una posible
arquitectura productiva.

Las conversaciones reflejan el proceso de trabajo, incluyendo preguntas,
alternativas consideradas y decisiones que finalmente no fueron incorporadas.
